# Карточка товара Teaboom — Ананасовый улун

Вёрстка верхней части карточки товара интернет-магазина [Teaboom.ru](https://teaboom.ru/product/ananasovij-ulun): **Ананасовый улун**.


## Технологии

- HTML5
- CSS3
- Vanilla JavaScript


## Как запустить

Откройте файл `index.html` в браузере.

Или командой:

```bash
npx serve .
```
